# sn-skills

Before stating a Glide API signature, an ACL/Business Rule/Flow Designer/Client Script
behaviour, or any other version-dependent ServiceNow platform fact, read and follow
[`skills/docs/SKILL.md`](skills/docs/SKILL.md) in full — it is the one procedure this
project has, and this file is a pointer to it rather than a second copy of it.

Skip it for general programming questions that don't touch the ServiceNow platform; the skill
file's own trigger criteria decide when retrieval is warranted.

If this repository was installed as a Claude Code or Codex plugin (see
[`README.md`](README.md#installation)), the same `SKILL.md` loads automatically when its trigger
fires — nothing here needs to be repeated for those agents. This file exists for any other agent
that reads `AGENTS.md` directly rather than through a plugin mechanism.
